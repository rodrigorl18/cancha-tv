# Cancha TV

Archivos públicos de la app web y APK Android/Android TV 1.0-preview.

## Publicación y actualizaciones

En Settings → Pages, seleccionar Deploy from a branch, la rama main y la carpeta / (root).

Para publicar cambios, exportar de nuevo el proyecto original con scripts/package-pages.mjs y actualizar estos archivos en este mismo repositorio. La app web recibe los archivos publicados al abrir o recargar con conexión. El APK aún se actualiza mediante una instalación manual de una nueva versión compatible.

## Android y TV

APK: [Descargar Cancha TV](./downloads/CanchaTV-Android-TV.apk). Android 6 o superior; no funciona en Vega OS. La compatibilidad física con teléfono, Android TV y Fire TV está pendiente de prueba.
